# PoliNetwork AKS → K3s migration

This repository is the durable decision and handoff record for the current AKS-to-K3s migration.

Start with:

- [`HANDOFF.md`](HANDOFF.md) — verified state on 23 August 2026, completed work, blockers, and the exact resume order;
- [`migration-plan.md`](migration-plan.md) — canonical technical and operational plan;
- [`migration-plan.html`](migration-plan.html) — generated, readable version of the plan;
- [`THREAD-RECOVERY.md`](THREAD-RECOVERY.md) — decisions recovered from the relevant T3 Code threads;
- [`legacy/`](legacy/) — superseded Docker Compose/OpenBao/doco.cd migration attempt, retained only as history.

## Critical boundary

Do not resume from `polinetwork-cd#vm` or copy its Compose architecture into the K3s target. New `polinetwork-cd` work starts from `origin/main`. Historical measurements and recovery evidence may be reused only after they are revalidated against the current environment.

## Editing the plan

Edit only `migration-plan.md`, then regenerate and verify:

```bash
make verify
```

`migration-plan.html` is generated by `scripts/build_report.py`; do not edit it directly. Never commit secret values, Terraform state, saved plans, database dumps, kubeconfigs, or evidence exports.
